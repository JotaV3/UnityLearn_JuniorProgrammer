## 🧠 Sobre o projeto

Este projeto foi criado como parte do curso oficial da Unity, com foco em desenvolver habilidades fundamentais de programação para jogos.

Durante o desenvolvimento, foram aplicados conceitos como:

- 🎮 Controle de jogador (movimentação de veículo)
- ⚙️ Física básica com Rigidbody
- 🚧 Interação com obstáculos
- 🧩 Organização de scripts em C#
- 🔄 Lógica de gameplay

---

## 🎯 Objetivo do jogo

Controlar o veículo e desviar dos obstáculos ao longo da pista.

---

## ⚙️ Tecnologias utilizadas

- 🧱 Unity (Engine)
- 💻 C#
- 🛠️ Visual Studio

---

## 🚀 Funcionalidades

- ✔️ Movimentação do veículo
- ✔️ Sistema de colisão
- ✔️ Obstáculos na pista
- ✔️ Controle via teclado
